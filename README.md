# Educação Financeira

## Sobre o tema

### Descrição

Material para estudo de educação financeira, com carga horária com 40 horas. O repositório conta com todo o material utilizando para esse curso. 

### Público alvo

Inicialmente, o material está sendo desenhado para alunos do ensino médio integrado ao curso técnico de administração, mas pode ser utilizado com outros públicos, bastando apenas uma breve adaptação.


#### Material base


Para o conteúdo desse curso, foi considerado um Caderno disponibilizado pelo Banco Central, entitulado [Caderno de Educação Financeira e Gestão de Finanças Pessoais - Banco Central](https://drive.google.com/file/d/1VjGOcE6qPl6eF-3GQANTdWhe5pTWK7Q4/view?usp=sharing) que aqui, está disponível de duas formas: um arquivo em PDF que está anexado nesse parágrafo, e o mesmo arquivo, direto do site do Banco Centro, que consta na seção Referências, desse documento.
